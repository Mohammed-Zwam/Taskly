# 🚀 Taskly

Taskly is a modern Project Management System built with **Angular** and **Tailwind CSS**, based on a professional **Figma UI design**.

This project was developed as part of an **Angular Mentorship Program**, where the goal is to simulate real software development environments, company workflows, and team collaboration while working on a production-like application connected to a real backend.

---

## 🎯 About the Project

Taskly helps teams organize and manage their work through a structured hierarchy:

```
Projects
   └── Epics
        └── Tasks
```

It provides an intuitive interface for managing projects, assigning work, tracking progress, and collaborating with team members.

This project is not just about building a UI.

- Git & GitHub workflow
- Conventional Commit messages
- Branching strategy
- Task breakdown & estimation
- Code reviews
- Clean and maintainable code
- Component reusability
- Responsive development
- Backend API integration
- Working with a real-world project structure
